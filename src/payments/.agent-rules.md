# src/payments 규칙

이 폴더가 유일한 활성 결제 코드다. `src/billing/`, `src/old/`는 보지도 말 것.

**금액 단위** — 항상 전(minor unit) 정수. 100전 = 1원.
필드명은 `amountMinor`. 비율 계산도 정수 연산으로 (`* 5 / 100` + `Math.floor`, `* 0.05` 금지).

**로그** — `lib/logger.js`의 `logPayment()`만 사용. `console.log` 금지.
한 건당 시작/종료 두 줄. 필드는 `event`, `order_id`, `amount_minor`, `currency`, `status`.

**에러** — 실패는 던진다. `{ ok: false }` 반환이나 콜백 금지.
종류를 구분한다: 필수값 누락 `Error`, 타입 오류 `TypeError`, 범위 오류 `RangeError`.

**테스트** — 고쳤으면 `npm test`. 통과 확인 전에는 끝난 게 아니다.

자세한 규칙: `docs/payment-rules.md`
