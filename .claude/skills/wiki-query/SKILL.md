# wiki-query

`_brain`에 이미 적힌 것만으로 답한다. 위키에 없으면 없다고 말한다.

## 절차

1. `_brain/index.md`를 읽어 관련 노드를 고른다. 목차로 못 찾으면 `_brain/` 전체를 grep 한다.
2. 노드 본문에서 답을 찾고, 그 노드의 `sources`에 적힌 raw 파일을 **직접 열어 원문을 확인**한다.
3. 답한다. 형식:
   - 답 (한두 줄)
   - **출처**: `[[노드이름]]` (`status`) → `_brain/raw/<원본>` 의 해당 문장
4. 노드에 `## 모순/주의`가 있고 질문과 관련되면 **반드시 함께 알린다.** 한쪽만 골라 답하지 않는다.
5. `status: draft`/`stub` 노드를 근거로 답할 때는 확정이 아님을 밝힌다.

## 위키에 없을 때

지어내지 않는다. 코드나 다른 문서에서 추론해 메우지도 않는다. 이렇게 답한다:

> 아직 위키에 없습니다. (`_brain/index.md`와 `_brain/` grep 확인)
> 근거가 될 만한 원본이 `_brain/raw/`에 있으면 `/wiki-ingest`로 먼저 넣으시겠습니까?

raw에는 있는데 노드로 정리만 안 된 경우도 "아직 위키에 없음"이다 — raw 경로를 알려주고 ingest를 제안한다.

## 금지

- 출처 없는 답. 노드 이름과 raw 경로 중 하나라도 빠지면 답으로 치지 않는다.
- 노드에 없는 내용을 그럴듯하게 채우는 것.
- 이 스킬로 `_brain`을 고치는 것. 읽기 전용이다. 수정은 `/wiki-ingest`.
