# wiki-ingest

`_brain/raw/`의 원본을 읽어 주제별 지식 노드로 옮긴다. 원본은 그대로 두고, 노드만 쌓인다.

## 절차

**① 규칙 먼저** — `CLAUDE.md`의 "## 지식 저장소(_brain) 규칙" 섹션과 `_brain/index.md`를 읽는다. 규칙과 이 스킬이 어긋나면 `CLAUDE.md`가 이긴다.

**② 추출** — 지정된 raw 파일에서 네 종류만 뽑는다: **결정**(무엇을 하기로 했나) · **관찰**(무엇을 알게 됐나) · **미결**(아직 안 정해진 것) · **용어**(팀 안에서만 통하는 말). 원문 표현을 임의로 다듬지 말고, 숫자·날짜·고유명사는 원문 그대로 옮긴다.

**③ 노드 배치** — 먼저 `_brain/index.md`와 기존 노드를 훑어 **같은 주제 노드가 있으면 거기에 병합**한다. 새 파일은 기존 어느 노드에도 속하지 않을 때만 만든다. 새 파일 남발 금지 — 한 항목 한 파일은 실패다.
- 위치: 결정 → `_brain/decision/`, 회의 기록 → `_brain/meeting/`, 사후 분석 → `_brain/postmortem/`
- frontmatter 필수:
  ```
  ---
  status: solid   # 확정된 결정 = solid, 미결·추정 = draft, 제목만 = stub
  sources: [_brain/raw/2026-08-12-week6.md]
  ---
  ```
- `sources`는 근거가 된 raw 경로 전부. 병합 시 기존 목록에 추가한다.

**④ 링크** — 관련 노드는 본문에서 `[[노드이름]]`으로 잇는다. 아직 없는 노드를 가리키는 링크도 괜찮다 — 다음에 만들 자리를 표시하는 것이다.

**⑤ 모순** — 새 정보가 기존 노드와 어긋나면 **기존 문장을 지우거나 고치지 않는다.** 노드 하단 `## 모순/주의` 섹션에 양쪽을 출처와 함께 병기한다.
```
## 모순/주의
- 8/6 노트는 "35줄 이내", 8/12 이후 실제 파일은 38줄. (출처: raw/2026-08-06-week5.md, CLAUDE.md)
```

**⑥ 기록** — `_brain/index.md` 목차에 새 노드를 추가하고, `_brain/log.md`에 한 줄 남긴다: `YYYY-MM-DD | ingest | 대상 raw → 만든/고친 노드`.

## 금지

- `_brain/raw/` 수정. 원본은 읽기 전용이다.
- 키·토큰·개인정보를 노드에 옮기는 것. 발견하면 그 항목은 건너뛰고 사용자에게 알린다.
- 모순 해소를 위해 한쪽을 삭제하는 것. 판단은 사람이 한다.
