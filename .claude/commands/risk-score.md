대상 diff를 5축으로 채점한다. **높을수록 위험**이다.

| 축 | 만점 | 본다 |
|---|---|---|
| Security | 30 | 시크릿·키·개인정보, 권한 확대, 외부 입력 검증 |
| Scope | 20 | 요청 범위 밖 변경, 건드린 파일·디렉터리 수 |
| Breaking | 20 | 공개 API 시그니처, 반환 형태, 호출부 동시 갱신 여부 |
| Tests | 15 | 대응 테스트 유무, `npm test` 통과 여부 |
| Migration | 15 | 데이터·설정·훅 스키마 변경, 롤백 가능성 |

각 축의 점수 근거를 한 줄씩 단다.

## 등급과 액션 (우리 팀 버전)

| 총점 | 등급 | 권장 액션 |
|---|---|---|
| 0~15 | 🟢 | 셀프 머지 가능 |
| 16~35 | 🟡 | 동료 1명 리뷰 |
| 36~60 | 🟠 | 교수님 리뷰 |
| 61+ | 🔴 | 머지 보류 · 설계 논의 |

## 출력

축별 표(축 | 점수 | 근거) + 총점 + 등급 + 액션 한 줄.

배점은 팀 가치관이다. 이견이 있으면 배점을 고치고 그 이유를 커밋 메시지에 남긴다.
