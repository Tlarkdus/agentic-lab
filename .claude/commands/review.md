`CLAUDE.md`와 `GOLDEN_RULES.md`를 읽은 뒤, `git diff`(스테이징이 있으면 `--cached`,
없으면 최근 커밋)를 아래 5항목으로 대조하라.

1. **헌법 4원칙 위반** — Think Before Coding / Simplicity First / Surgical Changes / Goal-Driven
2. **금지사항 저촉** — 부동소수 금액, `console.log` 직접 호출, 실패를 정상 반환값으로 감추기,
   `src/billing/`·`src/old/` 수정·참조
3. **테스트 동반 여부** — 코드 변경에 대응하는 테스트가 같이 왔는가, `npm test` 통과를 확인했는가
4. **범위 밖 변경 (Surgical)** — 요청 범위 밖의 코드·주석·포맷을 건드렸는가
5. **문서 갱신 필요** — 규칙 문서·`report-*.md`·`_brain/`이 같은 커밋에서 갱신돼야 하는가

## 출력

| 항목 | ✅/❌ | 근거(파일:줄) | 수정안 |
|---|---|---|---|

표 아래 한 줄 총평.

## 규칙

- 칭찬은 생략한다. 지적은 구체적으로.
- 근거는 반드시 `파일:줄` 형식으로 댄다. **근거 없는 ❌는 리뷰가 아니라 잔소리다.**
- ❌에는 수정안을 반드시 붙인다.
